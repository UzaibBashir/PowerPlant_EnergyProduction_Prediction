# Power Plant Energy Production Prediction

This project predicts the net energy output generated by a power plant using machine learning/Deep Learning. The model uses features such as ambient temperature, vacuum, atmospheric pressure, and relative humidity to estimate the target variable, PE (produced energy).

## Objective
Build and evaluate an artificial neural network (ANN) regression model that can predict power generation efficiently and accurately.

## Dataset
The dataset contains the following features:

- AT: Ambient Temperature
- V: Vacuum
- AP: Ambient Pressure
- RH: Relative Humidity
- PE: Produced Energy (Target Variable)

## Workflow
1. Load the dataset
2. Check for missing values
3. Split data into training and testing sets
4. Standardize feature values
5. Convert data to PyTorch tensors
6. Train a regression ANN model
7. Evaluate model performance using MSE and R² score

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- PyTorch
- Matplotlib

## Model
The project uses a feedforward neural network with:
- Input layer
- Two hidden layers with ReLU activation
- Output layer for regression prediction

## Evaluation
The model is evaluated using:
- Mean Squared Error (MSE)
- R² Score

## Files
- ANN_Regression_Model.ipynb: Training and evaluation notebook
- powerplant_data.csv: Dataset
- readme.md: Project overview

## Result
The project demonstrates how deep learning can be used for supervised regression to estimate power plant output based on environmental variables.
